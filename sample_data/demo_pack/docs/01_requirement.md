# 手機預借現金需求說明（虛構測試資料）

產品目標：讓持卡人從手機申請預借現金，查詢費用與交易結果。
適用卡別：第一階段希望同時支援正卡與附卡。
入帳帳戶：業務希望可匯入客戶指定的本行或他行帳戶。
交易驗證：每次申請需要簡訊一次性驗證碼。
每日限額：產品提案為每日新臺幣 100000 元，仍待風控確認。
費用揭露：送出交易前顯示手續費、利率及計息說明，使用者同意後才能送出。
結果通知：交易完成後提供手機推播通知。
紀錄查詢：使用者可查詢最近 90 天的交易紀錄。
失敗訊息：交易拒絕原因需提供可理解的提示，詳細揭露範圍待風控決定。

此文件及所有人名、規則、數字均為軟體測試用，不代表任何真實銀行政策。
