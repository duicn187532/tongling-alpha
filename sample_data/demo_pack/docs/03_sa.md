# 手機預借現金 SA（虛構測試資料）

文件版本：SA 測試版 0.3。
適用卡別：現有額度服務只提供正卡持卡人資格檢核，附卡需另行擴充。
入帳帳戶：現有撥款介面只支援本人本行活期性存款帳戶。
交易驗證：裝置綁定驗證與簡訊驗證碼可組合為兩種驗證因子。
系統互動：手機 App 呼叫驗證服務完成身分驗證，再呼叫卡片交易服務取得申請結果。
資料影響：卡片交易服務需保存申請編號、交易日期、金額、處理狀態與關聯驗證編號。
每日限額：需新增同日累計金額檢查，具體金額待正式需求確認。
結果通知：交易完成後呼叫通知服務發送手機推播。
紀錄查詢：現有交易查詢服務可提供最近 90 天交易紀錄。

所有系統名稱均為測試用邏輯名稱，不代表真實環境。
