# 彤靈談心測試文件包

全部內容皆為虛構測試資料，不構成真實金融政策。

- `docs/`：初始需求、政策及 SA，可透過專用資料夾掃描或個別上傳。
- `meetings/`：三場 VTT 逐字稿；建立會議時請填入 manifest 中的實際討論日期。
- `revision/`：完成 v1.0 後才加入的第四場會議，用於測試變更請求與 v1.1。
- `manifest.json`：一鍵 Demo 的檔案清單，範例內容不寫在程式邏輯中。

建議驗證：入帳帳戶與驗證方式應出現來源分歧；每日限額應保留待定，不應自動採最新文件定案。完成前三場會議確認後，核對人工決策，再產生 PRD。後續限額變更應保留舊版並建立新修訂。
