# 架構與信任邊界

彤靈 Alpha 是單主機應用。FastAPI 提供 API 與建置後的 React 前端；SQLite 儲存專案、來源、工作狀態與配對 session。上傳文件、產生的圖表及輸出也保存在主機的 `data/`。Ollama 可在同一主機提供模型；外部 OpenAI 相容 API 須由主機管理者明確設定。

```text
主機瀏覽器 ──> 127.0.0.1:8000 ──> API + SQLite + 文件 + 本機模型
遠端瀏覽器 ──> ngrok HTTPS ──> 127.0.0.1:8001 ──> 受限客戶端 API
```

8000 是管理入口，只允許 loopback 存取，不能作為反向代理或 ngrok 的目標。8001 是不同程序，僅開放客戶端路由；使用者透過短期配對碼取得持久 session，各自只可讀寫自己建立的專案。主機共用知識庫依專案檢索政策提供；不要把機敏文件放入允許共享的範圍。

技術設計的 AI 輸出只使用本案已連結且可檢索的來源段落，帶來源與段落 ID，並保留人工補正步驟。PRD 定版與 IT 交付另有版本與審閱檢查；使用者輸入的審閱者姓名目前不是組織身份驗證。工作狀態、檢索結果與模型 trace 會留在主機資料庫，不會由程式自動推送到 GitHub。

此架構適合個人或小團隊在可信任主機上試用；公開網路使用須啟用受限入口、保持主機更新，並依實際用途評估組織身份、備份、權限與稽核要求。
