# 部署、啟動與停止

本版提供 Windows 一鍵啟動。需求是 Python 3.12、Node.js 22.12 以上（含 npm）、可寫入的安裝資料夾。Ollama、ngrok 與公開搜尋 API 都是選用，不影響預設離線規則模式的啟動。首次安裝需連網下載 Python／Node 依賴，建立圖表時可能需要 Mermaid Chromium。

## 本機主機

1. 下載原始碼或解壓發行包，放到非系統目錄。
2. 雙擊 `start.cmd`。第一次啟動可能花數分鐘安裝依賴、建置前端及執行資料庫遷移。
3. 開啟 `http://127.0.0.1:8000`。`/api/health` 應回傳 `status: ok`、`gateway: false`。
4. 雙擊 `stop.cmd` 可關閉主機與本套件啟動的客戶端通道；也可在前景啟動視窗按 `Ctrl+C`。

若 8000 已被其他程序占用，啟動腳本會停止並提示，不會覆蓋資料。修改前端程式後重新啟動會重新建置，不會沿用過期畫面。`data/` 是唯一預設執行資料目錄；自訂專用資料夾可能位於其他位置，請連同它一起備份。**先關閉主機再備份 SQLite**；升級前請保留一份可還原備份。還原時先關閉系統，再將備份放回原位置。

## 分享受限客戶端

在主機安裝 ngrok 並於本機終端機執行 `ngrok config add-authtoken <權杖>`；權杖不要放入儲存庫。主機運作後執行 `Start-ClientAccess.ps1`。它會啟動 8001 客戶端、檢查健康狀態、建立 ngrok HTTPS 通道，並在主機顯示配對碼。只需關閉分享時執行 `Stop-ClientAccess.ps1`；主機可繼續使用。

客戶端腳本將程序 ID 與公開網址記在被 Git 忽略的 `data/`，停止時只終止此安裝資料夾啟動的對應程序。若程序記錄不符，腳本會拒絕停止，避免誤關其他服務。通道目標必須是 8001，不能是 8000；不要把管理端接到任何公網反向代理。

## 模型與搜尋

預設 `mock` 是標示清楚的離線規則模式。若要使用真實 AI，請自行安裝 Ollama 與模型，或在主機環境設定 `OPENAI_API_KEY` 後由主機設定頁選擇 OpenAI 相容提供者。公開同業搜尋可用免金鑰 Google News RSS；Tavily／Brave 金鑰只由主機環境變數 `TAVILY_API_KEY`／`BRAVE_SEARCH_API_KEY` 讀取。所有服務金鑰都不應放在程式碼、設定匯出或 issue 中。

## 故障排除

- 啟動視窗出現安裝或建置錯誤：先確認 Python、Node/npm 版本與網路，再重新執行 `start.cmd`。
- 8000／8001 已使用：確認是否已有彤靈程序，或用 `stop.cmd` 停止本資料夾的程序；不要直接終止不明程序。
- 客戶端無法配對：確認 8001 健康、ngrok 通道仍有效，並在主機取得新的配對碼。
- AI 沒反應：先在主機設定頁測試連線與實際生成；檢查模型是否已下載、Ollama 是否啟動，工作卡是否顯示失敗或等待。
- 資料庫遷移失敗：不要刪除 `data/`；保留錯誤訊息與備份後再排查。
